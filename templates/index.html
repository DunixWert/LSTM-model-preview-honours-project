Upload file format

One row per site per hour, same columns as dataset.xlsx:

Timestamp, Site_Name, ExpkWh, shortwave_radiation, cloud_cover, temperature_2m, precipitation, relative_humidity_2m, wind_speed_10m

Weather columns must already be scaled to 0..1. Site_Name is 1 to 7 (or "Site 3"). Each site needs more than 24 consecutive hours. Other columns are ignored.
